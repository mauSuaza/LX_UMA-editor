LX_UMA editors

Make your own wavetables and wave terrains for the Plaits models in LX_UMA, an unofficial custom firmware for the Erica Synths LXR Eurorack module. Each editor saves a .bin file for the SD card.

These are Mutable Instruments' Plaits editors by Emilie Gillet (MIT licence), adapted for LX_UMA: the audio transfer for a real Plaits is replaced by file downloads.

LX_UMA is a community project, not affiliated with or endorsed by Erica Synths or Mutable Instruments.
